Reset watchdog data

Use this before commissioning a gateway for a different site. This cannot be undone.

Data that will be cleared

  • Gateway site name and asset ID
  • People-counting camera and mobile-router details, saved web links and local network targets
  • ANPR camera connection and locally stored plate reads
  • People-counting history, watchdog events, status history, black-box and incident evidence

Items kept

  • Hardware watchdog protection and other watchdog policy settings
  • Recording disk setup, network interface configuration and installed software
  • TeamViewer installation, ID and password
  • Videosoft gateway configuration and CCTV recordings

Confirm reset

The watchdog services will restart after the data is cleared. Enter the local vsuser password and type RESET WATCHDOG.
