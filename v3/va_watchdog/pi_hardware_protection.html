Pi hardware protection

The Pi uses its native hardware watchdog through systemd. This is separate from application monitoring and service recovery.

Commissioning and support

Enabling the native watchdog is an attended setup step. From the Pi terminal:

sudo bash /opt/va-connect-watchdog-v3/v3/scripts/enable_pi_native_watchdog.sh

This protects against a system hang. It does not prove that an application freeze will trigger a hardware reset. Do not open the device with a second feeder.
